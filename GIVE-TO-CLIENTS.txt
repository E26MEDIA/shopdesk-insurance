# E26 — Give Insurance Desk to a client (simple)

## One-time setup (you do this ONCE)

1. On your Windows PC, build the installer:
   ```
   npm run desktop:dist:win
   ```
2. Upload `dist-desktop\ShopDesk-Setup-0.1.0.exe` to **Google Drive**
3. In admin → **Download**, paste the Google Drive direct link and save

Same download link for **every client**.

---

## For each new client (3 steps)

### 1. Create shop
Admin → **Shops** → Create shop (name, owner, phone)

### 2. Create license
Admin → **Licenses** → select shop → Create License

### 3. Email the client
After creating the license, click **Copy full message** or **Open in email**.

The message includes:
- Download link
- License key
- Install steps

**Send that email or WhatsApp. Done.**

---

## What the client does

1. Download the `.exe`
2. Install on Windows — the installer will ask for the verification key
3. Paste the license key you sent
4. Open Insurance Desk if it does not start automatically
5. Works offline after activation

---

## You do NOT send

- Source code
- Admin login
- GitHub link
- Your database

Only: **download link + license key**
